# 決策紀錄

本目錄存放本 ADE 的架構決策紀錄（ADR，Architecture Decision Record），記錄知識體系、skill 與團隊流程的設計當時考慮過的方案與選擇的理由。現況寫在 `hub/knowledge/` 各分類的入口檔與知識中；本目錄不注入 Forge，只在改變對應的設計時閱讀。

ADR 由 `ade-create-adr` skill 建立，撰寫規則與各狀態的意義見 `hub/knowledge/process/adr-writing.md`。全部 ADR 列在 [ADR 索引](./INDEX.md)，索引由 pre-commit hook 執行 `hub/skills/ade-create-adr/adr.js` 產生，不得手動編輯。
