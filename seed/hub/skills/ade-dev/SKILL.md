# ade-dev

規則全部在[開發流程的規則](kb:process/5ee9e6)，本 skill 不複述。

起手：讀該入口檔，依「誰在什麼時候讀哪份」只載入你這個角色需要的檔案。起手一律先讀[開發任務的狀態與檔案](kb:process/8ac32d)，做接手判讀與執行模式判讀，再依所在的關載入[六關的產出與過關判準](kb:process/8707ca)的對應段；派審查時讀[兩軸審查的契約](kb:process/5d2867)；auto 模式的 orchestrator 另讀[Spec Ready 與 auto-pilot 的規則](kb:process/724d2e)。派出的 worker 與審查者，prompt 同樣只給它們需要的部分，不整份貼上。
