# ade-dev-auto

規則全部在[開發流程的規則](kb:process/5ee9e6)，本 skill 不複述。

起手：讀[開發任務的狀態與檔案](kb:process/8ac32d)做接手判讀與執行模式判讀，再讀[批次串接的規則](kb:process/d1e46f)；逐一任務的 Spec Ready 判定與 auto-pilot 執行依[Spec Ready 與 auto-pilot 的規則](kb:process/724d2e)，其餘依 `ade-dev` 的角色載入規則。
