# 知識庫

本目錄是 ADE 的知識庫：團隊共用的知識，由 ADE 維護並注入每個 Forge。知識只能在 ADE 建立與修改，規則見[建立知識的規則](kb:process/7caa6d)。

## 查找方式

依是否知道要找的名稱，選用下列方式：

- **以名稱直接搜尋**：先讀本目錄的 `CONTEXT.md`，以 `_Avoid_` 把用詞換成正式名詞；再以正式名詞 grep 內文，以正式名詞的英文名 glob 檔名。命中多份檔案時，先讀各檔案 frontmatter 的 `description`，選出需要的再讀全文。
- **沿入口檔往下找**：搜尋找不到，或不知道知識庫有什麼時，從本檔的導覽選出分類，再讀該分類的 `README.md` 逐層往下。

知識中的引用 `[文字](kb:<分類>/<id>)` 是符號位址：在 `<分類>/` 下搜尋 frontmatter 為 `id: <id>` 的檔案，即可找到目標。

## 導覽

各分類的定位寫在各自的入口檔，依需要閱讀：

- `CONTEXT.md`：撰寫知識前確認正式名詞，或搜尋前換用正式名詞時閱讀
- [服務](kb:services/79bcb9)：開發某個服務前定位服務、取得 repo 與依賴時閱讀
- [流程](kb:process/2f0360)：做事前確認團隊的流程與慣例時閱讀
- [產品規格](kb:specs/f2e5d1)：確認產品功能目前應有的行為時閱讀
- [PRD](kb:prd/c66c02)：撰寫新需求，或確認某次開發的需求時閱讀
