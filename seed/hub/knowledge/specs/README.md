# 產品規格

本分類收錄全部的產品功能，包括單一服務就能完成的功能。產品規格的讀者是 PO；「服務可以自行描述的知識不收進 ADE」只適用於工程知識，不適用於產品的視角。

## 規則

產品規格遵守下列規則：

- 每個功能或產品領域一份 `.md`。
- 功能由哪些服務構成，由產品規格以服務名稱列出；服務的描述檔不回連產品規格。
- 產品規格描述現況。由 PRD 帶入、尚未開發完成的行為，以尚未實作標記標示。

## 尚未實作標記

由 PRD 帶入、尚未開發完成的行為，在區塊上方加上下列標記。格式必須逐字一致，skill 依此比對：

```md
> 尚未實作（[<PRD 標題>](kb:prd/<PRD 的 id>)）
```

標記遵守下列規則：

- 一行只標一份 PRD；同一區塊有多份進行中的 PRD 時，堆疊多行。
- 標記行緊貼在它描述的區塊，即標題或段落的上方。
- 開發完成後，由 `ade-align-spec` 核對實作，依 PRD 的 id 移除標記。

閱讀產品規格時，沒有標記的內容是已上線的現況，有標記的內容是已定案但尚未開發的行為。

## 導覽

本資料夾是集合型：新增或修改產品規格時，有對應的 PRD 就使用 `ade-prd-to-spec`，沒有就依[建立知識的規則](kb:process/7caa6d)撰寫。
