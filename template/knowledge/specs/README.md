# 產品規格（spec）

描述**當前**功能服務的規格，是長期維護、持續迭代的真相來源。每個功能／產品領域一個 md 檔。

跨服務的功能請寫明由哪些服務構成，並連回 `../services/` 下的對應服務檔。

## 尚未實作標記

由 PRD 帶入、還沒開發完成的行為，在區塊上方標記，**格式必須逐字一致**（工具與 skill 靠精確匹配移除）：

```
> 🚧 尚未實作（PRD: ../prd/YYYY-MM-DD-slug.md）
```

- 一行只標一個 PRD；同一區塊有多個進行中 PRD 時堆疊多行
- 標記行緊貼其描述的區塊（標題或段落）上方
- 開發完成後由 `ade-align-spec` skill 核對實作、依 PRD 檔名精準移除

讀 spec 時：無標記＝已上線的現況，有標記＝已定案但還沒做。
