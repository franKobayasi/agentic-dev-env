# 搜尋

本文件規範知識庫的搜尋：以用詞或檔名直接定位知識，不經過樹。搜尋讓樹不必完美，前提是用詞一致；用詞的規則見[詞彙表](./vocabulary.md)。

## 搜尋的方式

agent 以下列步驟搜尋知識：

1. 讀知識庫根目錄的 `CONTEXT.md`，以 `_Avoid_` 把要找的用詞換成正式名詞。
2. 以正式名詞 grep 知識的內文。
3. 以正式名詞的英文名 glob 檔名。

搜尋找不到目標時，改從知識庫根目錄的 `README.md` 沿入口檔逐層往下找。根目錄 `README.md` 說明查找方式的規定見[入口檔與索引檔](./navigation.md)。

## 用詞一致是前提

搜尋只能找到與搜尋用詞相同的內容。知識改用同義詞時，grep 會漏掉；檔名不使用正式名詞的英文名時，glob 會漏掉。因此搜尋的可靠程度取決於兩條規則：內文使用正式名詞，見[詞彙表](./vocabulary.md)；檔名使用正式名詞的英文名，見[檔名](./naming.md)。
